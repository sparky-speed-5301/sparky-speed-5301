        <b>Approach.</b> A reproducible NLP pipeline — deterministic preprocessing, TF-IDF and Bag-of-Words feature representations, three baseline classifiers, vectorizers fitted inside training folds only, stratified cross-validation, and an untouched holdout set reserved for final reporting.<br/>
